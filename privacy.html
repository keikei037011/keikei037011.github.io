プライバシーポリシー

最終更新日: 2026年10月11日

「個人用Googleアシスタント」（以下「本アプリ」）は、所有者本人が自分のGoogleアカウントのデータを利用するための、個人利用専用のアプリケーションです。本アプリは一般公開されておらず、所有者本人以外のアカウントを対象としていません。

1. アクセスするGoogleユーザーデータ

本アプリは、所有者本人の明示的な同意に基づき、以下のデータにアクセスします。

  • Google カレンダー（予定・誕生日などのイベント情報）
    用途: リマインダーの生成・通知など、本人への予定確認サポートのため。
  • Gmail（メールの閲覧・検索、下書きの作成）
    用途: 過去メールの参照による情報整理、および本人の指示に基づくメール下書きの作成。
    ※メールの送信は本人が行います。本アプリが自動で送信することはありません。

※利用していない権限（スコープ）があれば、この節から削除してください。実際に要求する権限と一致させてください。

2. データの利用目的

  • 本人への予定・記念日のリマインダー通知
  • 本人の指示に基づくメールの下書き作成支援
  • 本人の依頼に応じた情報の検索・整理

本アプリは、上記以外の目的、広告配信、データ販売、プロファイリングのためにGoogleユーザーデータを利用しません。Google API Services User Data Policy（Limited Use要件）を遵守します。

3. データの保存

  • 取得したデータは、所有者本人が管理するサーバー上に保存されます。
  • アクセスできるのは所有者本人のみで、第三者から閲覧できる状態にはしません。
  • 認証に必要なトークンは本人のサーバー内に保存され、公開されません。

4. 第三者への提供

処理の性質上、指示の解釈や文章生成のために、利用しているAIサービス（大規模言語モデルの提供者）へデータの一部が処理目的で渡ることがあります。その場合も、広告目的・AI学習目的での利用は行わず、Limited Use要件に沿って扱います。本人の指示がない限り、データを他の第三者に提供しません。

5. データの保持期間と削除

データは目的の達成に必要な期間のみ保持します。所有者が削除を指示した場合、または本アプリの利用を停止した場合、保存済みデータおよび認証トークンを削除します。

6. 同意の取り消し

いつでも Googleアカウントの「アクセス権を持つ第三者アプリ」 から本アプリのアクセス権を取り消すことができます。取り消し後、本アプリはデータへアクセスできなくなります。
